# Notificação de Menção de Arquivos

## Propósito
Reconhecer quais arquivos de regra influenciaram sua resposta para transparência.

## Diretrizes
- SEMPRE liste os arquivos de regra referenciados ao final das respostas
- Formato: "Arquivos referenciados: filename.md - breve descrição"
- Mantenha descrições com menos de 10 palavras
